Первая лабораторная работа по предмету "Web-технологии": HTML-страница "О себе" (1 вариант: "Студент-разработчик").

Структура:
<header> – шапка с моим именем/фамилией и заголовком страницы;
<main> – основной контент;
Две секции <section>: «Навыки» (языки программирования, которыми я лучше всего владею) и «Проекты» (мои учебные проекты);
<aside> – боковая панель с краткой информацией (мои любимые технологии);
<footer> – подвал с копирайтом и годом;
Одно изображение (аватар) с атрибутами src, alt, width, height;
Форма обратной связи: поля «Имя», «Email», «Сообщение», и кнопка отправки,
Цветовая гамма: сине-белая.

Используемые технологии:
-HTML5
-Visual Studio Code
-GitHub

Как запустить:
1. Скачайте или клонируйте репозиторий;
2. Откройте файл index.html в любом браузере.
